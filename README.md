# Meraviglie-urbane
Un Viaggio tra le Piazze dei Capoluoghi Questo progetto nasce per raccontare l’anima della Sicilia attraverso le sue piazze principali. Il sito offre un tour virtuale tra i nove capoluoghi di provincia, svelando la bellezza architettonica di ogni piazza e fornendo consigli preziosi su cosa visitare nelle immediate vicinanze.
